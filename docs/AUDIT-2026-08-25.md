## PART 2 — GAPS FOUND BY THIS AUDIT (all actionable)

G1. **Responsive/adaptive layout**: single 1100px breakpoint; rail/orchestrator don't adapt at 1440+/900-/720-. Research bar: flex/grid intrinsic sizing (Vercel guidelines), verified at laptop/mobile/ultra-wide.
G2. **Accessibility pass 1**: aria-labels on icon-buttons incomplete; overlay Esc returns focus to opener inconsistently; no skip-to-content; live regions absent for status strip (screen readers miss state changes). JetBrains bar: section-jump shortcut, predictable Alt-menu behavior, non-visual feedback for caret-on-error.
G3. **EGRESS badge is decorative** — should reflect .aide/logs/egress.log (needs tiny GET /api/egress/recent).
G4. **DIAGNOSTICS badge not click-through** — should summarize top issues into thread.
G5. **Onboarding checklist frozen at 3 steps** — flow law wants 5 (add APPROVE + VERIFY steps wired to real events).
G6. **Replace-in-files lacks mask scoping** (incident-proven need).
G7. **Session persistence covers engine only** — add last-open-file + panel states.
G8. **Ships telemetry invisible** — ships.log has data, no surface.
G9. Debug UI intentionally deferred (usage data). W7 RAG '#' palette mode, W8 recovery cards, W9 installer unchanged on ladder.
