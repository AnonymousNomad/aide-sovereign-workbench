# AIDE Engineering Standards: Research Basis

This note records the technical sources behind AIDE Engineering Standards.
It intentionally avoids fictional, personality-based, or mythology-based
product language.

## Applied Principles

| Source | AIDE practice |
| --- | --- |
| VS Code trust and safety | Review diffs, approve side effects, checkpoint, revert, and sandbox execution. |
| Anthropic agent guidance | Prefer simple workflows, ground progress in tool output, and add autonomy only when measured. |
| LSP and DAP | Use standard protocols for language intelligence and debugging. |
| GitHub repository guidance | Publish clear documentation, security policy, contribution rules, CI, and honest status. |
| GNOME HIG | Use clear hierarchy, adaptive layout, keyboard support, accessibility, and consistent feedback. |

## Engineering Rule

Trust is earned by reproducible behavior, tests, security boundaries, and clear
limitations. No persona or slogan substitutes for evidence.
