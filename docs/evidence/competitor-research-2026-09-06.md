## Gap decisions

The priority is not to copy every UI feature. The differentiators worth preserving are local-only operation, explicit operator approval, deterministic routing, and a visible evidence chain. The closest competitor gaps that can be safely closed in this pass are:

1. **Compartmentalized lifecycle audit events.** Windsurf's pre/post hook model demonstrates that every read, write, command, MCP call, prompt, and response should be observable and blockable. AIDE currently records tool and approval state, but the audit must verify whether all boundary events have one durable trajectory record.
2. **Subagent/background execution.** Cursor and Windsurf expose isolated concurrent work. AIDE's catalog contains a subagent-dispatch skill, but current route comments indicate runtime PR B is not wired. This is a high-confidence unfinished item; do not claim parity until an actual parent/child task is proven.
3. **Memory retention proof.** Helix routing is implemented, but a 30-day retention contract needs a boundary test (expiry, compaction, and restart) and a user-visible state. Empty Helix bootstrap must remain explicit.
4. **Cockpit canary.** Backend agent-loop and bundle-card acceptance are proven through HTTP and scripts, but the real browser path must be verified before claiming end-to-end product readiness. The legacy `app.js` remains protected; any UI work should be a surgical route toggle and render branch only.
5. **Model-quality benchmark.** Current results establish harness correctness, not that every model can select tools or complete coding tasks. A pinned, per-model-class canary is required before performance claims.

## Research-backed release posture

The audit will treat the first two gaps as implementation candidates, and will not broaden scope into a cockpit rewrite, cloud/background execution, or training work. Each fix must have a real task, a rejection/boundary case, a durable-state assertion, and a regression run. See `docs/evidence/real-task-verification-2026-09-06.md` for the current accepted task evidence and `docs/evidence/skill-catalog-audit-2026-09-06.md` for catalog counts.
