## Known issues / environment gotchas

- **Node v26.4.0**: plugin sandbox uses `--permission` (the flag `--experimental-permission` was REMOVED in Node 24). Grants are capability-gated and network is deny-by-default. See `plugins/manager.mjs`.
- **`python` = Windows Store stub**: tutor checks and DAP need `AIDE_PYTHON` (or a resolvable interpreter) — precedence is `AIDE_PYTHON` → `python3` → `python`.
- **Port 4173**: `npm test` fails with `EADDRINUSE` if a stale dev server is running. Check/kill before testing.
- **`gh` CLI not installed** locally — CI status must be checked via GitHub web UI.
- **No Rust toolchain locally** — Tauri build/installer work is CI-only.
