# Support

## Before Opening An Issue

1. Run `npm run doctor`.
2. Run `npm test`.
3. Include the failing command, version, operating system, and relevant local
   daemon output.
4. Do not include credentials, private source, model weights, or private data.

## Scope

AIDE is an offline-first pre-production workbench. Model quality, runtime
compatibility, language servers, debugger adapters, and plugins depend on the
local installation and are reported explicitly by the doctor and status views.
